# 达达利亚的行囊

一款浏览器里的背包肉鸽。达达利亚站在左边自动扔出背包里的武器，敌人从右边走来。开局先逛商店，把武器放进背包，再一波一波打下去。

在线试玩：[https://tatartatarlia.github.io/dada-rogue/](https://tatartatarlia.github.io/dada-rogue/)

## 怎么玩

- 开局是 3×3 的空背包。商店每次给出 3 件武器。1–20 波每波再送 1 格空位，21–40 波每 2 波送 1 格，41 波起每 3 波送 1 格。第一波的三件货会避开过不了这一波的组合（例如只有飞镖和燃烧瓶）；刷新同样如此。
- 武器可以先拖到背包任意位置。点一下背包里的武器，才会出现旋转按钮。压住别的武器或超出背包时，不能进入下一波。
- 背包里的武器可以拖回商店放回去。商店每波只能刷新一次，已经放进背包的武器会留下。
- 空格子贴着背包任意一边放下就能扩容。一次给两格时，它们是连在一起的。
- 两件相同等级的武器叠在一起，会合成一件高一级的武器。攻击力是原先两件加起来的 1.1 倍。不同的武器邻接，会触发不同效果；点上方的「规则」可以查看每一种。
- 每打完 5 波，进下一家商店之前会弹出三张事件，只能选一张。断流、至冬的权衡、冰封之痕选中后才揭晓结果；愚人众军械库和魔王武装会先把结果写在卡上。
- 打完一波会回满生命，再进商店。生命归零时，达达利亚在至冬的寒风里撑到这一波；在商店或战斗里选择结算，则是收起武器，这场战斗到此为止。执行官的试炼打完 50 波会颁发奖章。
- 开始时可选两种模式。执行官的试炼固定 50 波，敌人血量指数 1.10，通关次数记在历史记录的奖章旁。达达利亚的极限没有尽头，要点开后再选简单、普通、困难，血量指数分别是 1.09、1.10、1.11。历史记录要点开才展开，里面有试炼通关次数、三种难度各自到达的波数，以及最近一局。

武器都能旋转。占格如下：

| 武器 | 占格 | 特点 |
| --- | --- | --- |
| 斧头 | 3 格，上排 2、下排 1 | 出手勤，单下不算重 |
| 飞镖 | 1 格 | 出手最快，伤害最低 |
| 短剑 | 竖着 2 格 | 连斩，伤害偏低 |
| 燃烧瓶 | 竖着 2 格 | 命中后再燃烧一段时间 |
| 炸弹 | 2×2 | 单下最高，间隔最慢，能溅射 |
| 虚弱药剂 | 3 格，上排 1、下排 2 | 落点留下药雾，雾中移速降至 48%，受到的伤害提高 20% |

商店武器会随波数变强：1–3 波全是 1 级，之后逐渐出现 2 级、3 级，13 波起偶尔出现 4 级。21 波起，商店最高等级等于背包最高等级减 3，并且不会低于 4 级。原先按波数抽等级的权重还在，只是整档往这个上限靠。2 级和 4 级还有额外效果：飞镖同时打 2 个、4 级打 3 个目标；短剑概率连打两下、4 级连打三下且概率更高；斧头溅射附近 2 个敌人、4 级溅射 3 个且伤害更高；炸弹爆炸范围扩大、4 级留下燃烧区域；燃烧瓶烧得更久、4 级燃烧伤害可叠加；虚弱药剂药雾更大、4 级减速和易伤更强。3 级沿用 2 级的额外效果。所有武器都会暴击，暴击率是 20% 加上背包内最高武器等级的 10%，暴击伤害额外是 40% 加上最高等级的 20%。暴击率超过 100% 时，溢出的每 1% 变成 2% 暴击伤害。燃烧这类持续伤害也会暴击。

敌人生命 = 基础生命 × (1 + 0.25 × 波数) × 指数 ^ 波数。执行官的试炼指数是 1.10。达达利亚的极限里，简单 1.09、普通 1.10、困难 1.11。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端里给出的地址。常用命令：

```bash
npm run build   # 类型检查并打包到 dist
npm run preview # 预览打包结果
npm run lint
```

## 改数值

伤害、生命、敌人数量、商店等级和画面尺寸都在 [`src/config.ts`](src/config.ts) 顶部的 `CONFIG` 里，每项有中文注释。武器的攻击间隔不要超过 `maxAttackInterval`（0.5 秒）。

## 部署

推送到 `main` 后，[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) 会构建并发布到 GitHub Pages。

仓库需要先打开 Pages，并把 **Source** 设为 **GitHub Actions**：

[https://github.com/Tatartatarlia/dada-rogue/settings/pages](https://github.com/Tatartatarlia/dada-rogue/settings/pages)

打包时的资源路径是 `/dada-rogue/`，对应上面的项目站点地址。本地开发不受影响。
